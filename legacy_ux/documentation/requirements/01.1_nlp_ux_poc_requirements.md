# 01 NLP POC UX

Provide a basic user experience to bring in the context from the NLP analysis endpoint and display it to the user.

## 01.1 On demand NLP panel

Create a react component which takes as a property a string to analyze, and if the user clicks the `analyze` button, calls the `/api/nlp_analysis` endpoint.

- The API call should not be triggered until the user clicks the analyze button

- Once pressed, if the text to be analyzed changes, the API should be called again with the new text with a sensible debounce of 1 second

- The NLP analysis data should be presented to the user in a technical manner for now
