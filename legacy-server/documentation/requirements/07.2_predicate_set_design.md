## 07.2.1 Database Schema Changes

### 07.2.1.1 New Predicate Table

Create a new `predicates` table with the following schema:

```sql
CREATE TABLE predicates (
    id TEXT PRIMARY KEY DEFAULT (uuid4()),
    identifier TEXT UNIQUE NOT NULL,
    title TEXT UNIQUE NOT NULL,
    definition TEXT,
    mapping TEXT,  -- JSON string for reference mappings
    date_created DATETIME DEFAULT (datetime('now')),
    date_modified DATETIME DEFAULT (datetime('now'))
);

-- Index for efficient lookup by identifier
CREATE INDEX idx_predicates_identifier ON predicates(identifier);

-- Trigger to update date_modified on updates
CREATE TRIGGER update_predicates_date_modified 
    AFTER UPDATE ON predicates
    FOR EACH ROW
BEGIN
    UPDATE predicates SET date_modified = datetime('now') WHERE id = NEW.id;
END;
```

### 07.2.2.4 Utility Functions

```python
def generate_identifier_from_title(title: str) -> str:
    """
    Generate a code-safe identifier from a title.
    Converts to lowercase and replaces spaces/special chars with underscores.
    """
    import re
    # Convert to lowercase
    identifier = title.lower()
    # Replace whitespace and special characters with underscores
    identifier = re.sub(r'[^\w]', '_', identifier)
    # Remove multiple consecutive underscores
    identifier = re.sub(r'_+', '_', identifier)
    # Remove leading/trailing underscores
    identifier = identifier.strip('_')
    return identifier

def validate_predicate_set(predicate_identifiers: List[str], db: Session) -> bool:
    """
    Validate that all predicate identifiers in a set exist in the database.
    """
    if not predicate_identifiers:
        return True
    
    existing_count = db.query(Predicate).filter(
        Predicate.identifier.in_(predicate_identifiers)
    ).count()
    
    return existing_count == len(predicate_identifiers)
```

## 07.2.5 ConceptNet Integration

### 07.2.5.1 Manual Predicate Import

Provide API endpoints to allow manual import of ConceptNet relations as predicates:

```python
def import_conceptnet_predicates(db: Session, relations: List[str] = None) -> List[Predicate]:
    """
    Import specific ConceptNet relations as predicates with proper mapping.
    If relations is None, import all configured relations.
    """
    from config import get_settings
    
    settings = get_settings()
    available_relations = settings.concepcy_config["relations_of_interest"]
    
    # Use specific relations or all available ones
    relations_to_import = relations if relations else available_relations
    
    predicates = []
    for relation in relations_to_import:
        if relation not in available_relations:
            continue  # Skip invalid relations
            
        identifier = relation.lower()
        
        # Check if already exists
        existing = db.query(Predicate).filter_by(identifier=identifier).first()
        if existing:
            continue
            
        # Create mapping
        mapping = {
            "conceptnet": {
                "relation": relation,
                "url": f"https://conceptnet.io/r/{relation}",
                "description": f"ConceptNet relation type: {relation}"
            }
        }
        
        predicate = Predicate(
            identifier=identifier,
            title=relation,
            definition=f"ConceptNet relation: {relation}",
            mapping=json.dumps(mapping)
        )
        
        db.add(predicate)
        predicates.append(predicate)
    
    db.commit()
    return predicates
```

### 07.2.5.2 Bidirectional Mapping

Support mapping predicates back to ConceptNet relations:

```python
def get_conceptnet_relation_for_predicate(predicate: Predicate) -> Optional[str]:
    """
    Extract ConceptNet relation from predicate mapping.
    """
    if not predicate.mapping:
        return None
        
    try:
        mapping = json.loads(predicate.mapping)
        return mapping.get("conceptnet", {}).get("relation")
    except (json.JSONDecodeError, KeyError):
        return None
```

## 07.2.6 Validation Logic

### 07.2.6.1 Predicate Set Validation

When updating a `TermRelationship` where both terms are in the same domain:

```python
def validate_term_relationship_predicate(
    relationship: TermRelationship, 
    db: Session
) -> bool:
    """
    Validate that the predicate is allowed for this relationship.
    """
    # Get source and target terms
    source_term = db.query(Term).filter_by(id=relationship.source_term_id).first()
    target_term = db.query(Term).filter_by(id=relationship.target_term_id).first()
    
    if not source_term or not target_term:
        return False
    
    # If terms are in the same domain, check domain predicate set
    if source_term.domain_id == target_term.domain_id:
        domain = db.query(Domain).filter_by(id=source_term.domain_id).first()
        
        if domain and domain.predicate_set:
            try:
                allowed_predicates = json.loads(domain.predicate_set)
                return relationship.predicate in allowed_predicates
            except json.JSONDecodeError:
                return True  # If invalid JSON, allow all predicates
    
    return True  # No restrictions for cross-domain relationships
```

### 07.2.6.2 Identifier Uniqueness

Ensure predicate identifiers remain unique:

```python
def validate_predicate_identifier(identifier: str, predicate_id: str, db: Session) -> bool:
    """
    Validate that a predicate identifier is unique.
    """
    existing = db.query(Predicate).filter(
        Predicate.identifier == identifier,
        Predicate.id != predicate_id
    ).first()
    
    return existing is None
```

## 07.2.9 Notes

1. **Backward Compatibility**: The migration maintains backward compatibility by preserving existing predicate strings while adding new predicate ID references.

2. **Performance**: Indexes on `predicates.identifier` and foreign key relationships will ensure efficient lookups.

3. **Extensibility**: The JSON mapping field allows for future integration with other predicate vocabularies beyond ConceptNet.

4. **Validation**: Domain-level predicate sets provide fine-grained control over allowed relationships within specific domains.

5. **Data Integrity**: Foreign key constraints and validation logic ensure referential integrity between predicates and their usage.
