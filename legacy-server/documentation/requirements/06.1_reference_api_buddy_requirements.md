# 6.1 Reference API Buddy Inclusion

Optionally allow reference API requests to be routed through the `reference_api_buddy` python package to provide caching proxy capabilities in order to reduce strain on upstream servers and reduce any costs associated with repeated calls.

## 6.1.1 Reference API Buddy Examples

`reference_api_buddy` is a side project and since it is not well-established these examples are provided to show how to use it.

This is a basic usage example:

```python
from reference_api_buddy.core.proxy import CachingProxy

# Example demonstrating cache-first throttling
config = {
    "domain_mappings": {
        "api": {"upstream": "https://api.example.com"}
    },
    "throttling": {
        "domain_limits": {"api": 2}  # Very restrictive: 2 requests per hour
    }
}

proxy = CachingProxy(config)
proxy.start(blocking=False)
```

## 6.1.2 Caching Proxy Configuration

The configuration to enable the caching proxy should be a binary `EnableCachingProxy` flag for each reference API, bundled in the `config` payload as a dict where the keys represent the individual reference APIs:

- If enabled for a reference API, when the `pipeline` is initialized it should be configured to use the caching proxy

  - The elements of the pipeline that should be considered reference APIs are: `concepcy` and `spacy_dbpedia_spotlight`

- For each Reference API, there should be a standard `reference_api_buddy` configuration which is invoked, the end user should not need to configure the details of the `reference_api_buddy` configuration

- If `EnableCachingProxy` is disabled for all reference APIs then `reference_api_buddy` should not be started

- If the configuration changes while the app is running, the pipeline should be reloaded and `reference_api_buddy` should be loaded if needed

### 6.1.2.1 Concepcy Configuration

To configure `concepcy` to use the caching proxy, configure it to use the proxy as the `url`:

```python
nlp.add_pipe(
    "concepcy",
    config={
        "url": "http://127.0.0.1:18080/conceptnet/query?node=/c/{lang}/{word}&other=/c/{lang}",
        # ... other config ...
    },
)
```

The `reference_api_buddy` config to go with that is:

```python
config = {
    "server": {
        "host": "127.0.0.1",
        "port": 18080,
    },
    "domain_mappings": {
        "conceptnet": {
            "upstream": "https://api.conceptnet.io"
        }
    },
    "throttling": {
        "domain_limits": {"conceptnet": 3600 }
    }

    # ... other config ...
}
```

### 6.1.2.2 Spacy DBpedia Spotlight Configuration

To configure `spacy-dbpedia_spotlight` to use the caching proxy set the `dbpedia_rest_endpoint` when adding the pipe to `spacy`:

```python
  nlp.add_pipe('dbpedia_spotlight', config={'dbpedia_rest_endpoint': 'http://127.0.0.1:18080/dbpedia_spotlight'})
```

The `reference_api_buddy` config to go with that is:

```python
config = {
    "server": {
        "host": "127.0.0.1",
        "port": 18080,
    },
    "domain_mappings": {
        "dbpedia_spotlight": {"upstream": "https://api.dbpedia-spotlight.org/en/"}
    },
    "throttling": {
        "domain_limits": {"dbpedia_spotlight": 3600 }
    }

    # ... other config ...
}
```
