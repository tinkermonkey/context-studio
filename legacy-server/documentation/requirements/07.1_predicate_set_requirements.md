# 07.1 Predicate Sets

Users should be able to build sets of predicates used to link their terms. They should be able to map their predicate set back to reference data sets such as ConceptNet. They should also be able to provide definitions for each predicate to enhance the common understanding of the relationship meaning.

## 07.1.1 Predicate Data Model

The predicate data model must allow for:

- An `id` which is a UUID v4 and should be auto-generated at creation
- An `identifier` which is a code-safe no whitespace identifier which defaults to the `lower_case_with_underscores` version of the `title` at time of creation, this must be unique
- A `title` which is required and can contain whitespace and must be unique
- A `definition` field which is a long string and is optional
- A `mapping` field which is a JSON string and is optional
- A `date_created` which is set at time of creation
- A `date_modified` which is updated when the record is updated

## 07.1.2 Predicate Data Links

The predicate data model will be able to be linked to other data:

- `Layer` has an existing `primary_predicate` field which should be removed
- `Domain` should have a `primary_predicate` field (optional) added to it which will contain the `identifier` value of a `Predicate` record
- `Domain` should have a `primary_predicate_id` field (optional) added which will contain the `id` value of a `Predicate` record
- `TermRelationship` has an existing `predicate` field which will contain the `identifier` value of a `Predicate` record
- `TermRelationship` should have a `predicate_id` field (optional) added which will contain the `id` value of a `Predicate` record

The `Layers` API should be updated to remove the `primary_predicate` field.

The `Domain`, and `TermRelationship` APIs should be updated to accept an `id` for a `Predicate` record, and if provided, read the `identifier` value from that record.

## 07.1.3 Predicate Reference Sets

`Predicate` records should be able to be mapped back to reference system predicate sets:

- The `ConceptNet` predicate set configured in `config.py` as the `relations_of_interest` list in the `concepcy` config

## 07.1.3 Predicate Set Management

`Domain` should be updated so that it can (optionally) be configured to have a fixed set of `predicate` records that `term` records in that `domain` can link to:

- `Domain` should be updated to have a `predicate_set` field which accepts a JSON string containing an array of acceptable `Predicate` record `identifier` values
- If a `term_relationship` links two nodes in the same `domain` which has a defined `predicate_set`, updating that `term_relationship` should cause validate that the provided `predicate` identifier is in the set of valid identifiers for that domain
