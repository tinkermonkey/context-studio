# 3.2 Predicates Design

This document outlines the detailed design for implementing predicate management functionality as specified in requirements 3.1. The design follows existing patterns in the codebase and integrates seamlessly with the current architecture.

## 3.2.1 Architecture Overview

### 3.2.1.1 Data Model Changes

Based on the OpenAPI schema analysis, the data model has been updated as follows:

**Layer Model Changes:**
- **Removed**: `primary_predicate` field from `LayerCreate` and `LayerOut` types
- Layers now focus purely on organizational structure without predicate constraints

**Domain Model Changes:**
- **Added**: `primary_predicate_id?: string` field to `DomainCreate` and `DomainOut` types  
- **Added**: `predicate_set?: string[]` field for multiple predicate associations
- **Added**: `primary_predicate?: string` (computed field) in `DomainOut` for display purposes

**Predicate Model (New):**
```typescript
// From OpenAPI schema
interface PredicateCreate {
  title: string;
  definition?: string;
  mapping?: Record<string, never>;
  identifier?: string;
}

interface PredicateOut {
  title: string;
  definition?: string;
  mapping?: Record<string, never>;
  id: string;
  identifier: string;
  date_created: string;
  date_modified: string;
}
```

**UX Design for Predicate Set Selection:**

The predicate set selector provides a multi-select interface for domains to associate with multiple predicates. This design balances usability with the complexity of managing multiple selections.

**Component Structure:**

1. **Multi-Select Dropdown**
   - Dropdown button shows count: "3 predicates selected" or "Select predicates..."
   - Opens to reveal checkbox list of all available predicates
   - Search bar at top for filtering large predicate lists
   - Scrollable list with virtual scrolling for performance

2. **Selected Items Display**
   - Below the dropdown: horizontally scrolling row of selected predicate "pills"
   - Each pill shows predicate title with X button to remove
   - Pills are color-coded or consistently styled
   - Empty state shows helpful text: "No predicates selected"

3. **Visual Hierarchy**
   - Primary predicate (if selected) is visually distinguished in the set
   - Could use different styling, icon, or "PRIMARY" badge
   - Ensures users understand the relationship between primary and set

**Interaction Behaviors:**

1. **Smart Defaults**
   - If user selects a primary predicate, auto-add it to predicate set
   - If user removes primary predicate from set, clear primary predicate field
   - Prevent duplicate selections between primary and set

2. **Validation Logic**
   - Primary predicate must be included in predicate set (auto-enforced)
   - Maximum predicate set size (configurable, default: unlimited)
   - Warning if no predicates selected at all

3. **Search and Filter**
   - Real-time search within predicate dropdown
   - Filter by predicate properties (title, identifier, definition)
   - Recent/frequently used predicates shown first

**PredicateSetSelector Implementation Details:**

```typescript
const PredicateSetSelector: React.FC<PredicateSetSelectorProps> = ({
  value = [],
  onSelectionChange,
  placeholder = "Select predicates...",
  disabled = false,
  maxSelections
}) => {
  const [isOpen, setIsOpen] = useState(false);
  const [searchTerm, setSearchTerm] = useState("");
  const { data: predicates, isLoading } = usePredicates();
  
  // Filter predicates based on search
  const filteredPredicates = useMemo(() => {
    if (!predicates?.data) return [];
    return predicates.data.filter(predicate =>
      predicate.title.toLowerCase().includes(searchTerm.toLowerCase()) ||
      predicate.identifier.toLowerCase().includes(searchTerm.toLowerCase())
    );
  }, [predicates, searchTerm]);

  const handleTogglePredicate = (predicateId: string) => {
    const newSelection = value.includes(predicateId)
      ? value.filter(id => id !== predicateId)
      : [...value, predicateId];
    
    // Check max selections limit
    if (maxSelections && newSelection.length > maxSelections) {
      return; // Could show toast notification
    }
    
    onSelectionChange(newSelection);
  };

  return (
    <div className="relative">
      {/* Dropdown Button */}
      <Button
        variant="outline"
        onClick={() => setIsOpen(!isOpen)}
        disabled={disabled}
        className="w-full justify-between"
      >
        <span>
          {value.length === 0 
            ? placeholder 
            : `${value.length} predicate${value.length !== 1 ? 's' : ''} selected`
          }
        </span>
        <ChevronDown className="h-4 w-4" />
      </Button>

      {/* Selected Items Pills */}
      {value.length > 0 && (
        <div className="mt-2 flex flex-wrap gap-1">
          {value.map(predicateId => {
            const predicate = predicates?.data?.find(p => p.id === predicateId);
            return predicate ? (
              <Badge key={predicateId} className="flex items-center gap-1">
                {predicate.title}
                <X 
                  className="h-3 w-3 cursor-pointer hover:text-red-500" 
                  onClick={() => handleTogglePredicate(predicateId)}
                />
              </Badge>
            ) : null;
          })}
        </div>
      )}

      {/* Dropdown Content */}
      {isOpen && (
        <div className="absolute z-10 mt-1 w-full bg-white border rounded-md shadow-lg">
          {/* Search Bar */}
          <div className="p-2 border-b">
            <TextInput
              placeholder="Search predicates..."
              value={searchTerm}
              onChange={(e) => setSearchTerm(e.target.value)}
              icon={Search}
            />
          </div>
          
          {/* Predicate List */}
          <div className="max-h-60 overflow-y-auto">
            {isLoading ? (
              <div className="p-4 text-center">
                <Spinner size="sm" />
              </div>
            ) : filteredPredicates.length === 0 ? (
              <div className="p-4 text-center text-gray-500">
                No predicates found
              </div>
            ) : (
              filteredPredicates.map(predicate => (
                <div
                  key={predicate.id}
                  className="flex items-center p-2 hover:bg-gray-50 cursor-pointer"
                  onClick={() => handleTogglePredicate(predicate.id)}
                >
                  <Checkbox
                    checked={value.includes(predicate.id)}
                    onChange={() => handleTogglePredicate(predicate.id)}
                    className="mr-2"
                  />
                  <div className="flex-1">
                    <div className="font-medium">{predicate.title}</div>
                    {predicate.definition && (
                      <div className="text-sm text-gray-500 truncate">
                        {predicate.definition}
                      </div>
                    )}
                  </div>
                </div>
              ))
            )}
          </div>
        </div>
      )}
    </div>
  );
};
```

**Table Display Design:**

In the DomainsTable, the predicate set is displayed as:

```typescript
// Column definition for predicate_set
columnHelper.accessor("predicate_set", {
  cell: (info) => {
    const predicateSet = info.getValue();
    const primaryPredicate = info.row.original.primary_predicate;
    
    if (!predicateSet || predicateSet.length === 0) {
      return <span className="text-gray-400">None</span>;
    }
    
    return (
      <div className="flex flex-wrap gap-1">
        {/* Show primary predicate first with special styling */}
        {primaryPredicate && (
          <Badge color="blue" size="sm">
            {primaryPredicate} (PRIMARY)
          </Badge>
        )}
        
        {/* Show count of additional predicates */}
        {predicateSet.length > 1 && (
          <Badge color="gray" size="sm">
            +{predicateSet.length - 1} more
          </Badge>
        )}
        
        {/* Tooltip with full list on hover */}
        <Tooltip content={
          <div>
            <p className="font-medium">All Predicates:</p>
            <ul className="mt-1">
              {predicateSet.map(id => (
                <li key={id}>• {getPredicateTitle(id)}</li>
              ))}
            </ul>
          </div>
        }>
          <Info className="h-3 w-3 text-gray-400 ml-1" />
        </Tooltip>
      </div>
    );
  },
  header: () => "Predicates",
}),
```

This design ensures that predicate set management is intuitive while maintaining the relationship between primary predicates and the broader predicate set.
