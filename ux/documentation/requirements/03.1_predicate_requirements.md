# 3.1 Predicates

The end user should be able to manage the set of predicates for their dataset and map those to domains and relationships.

## 3.1.1 Data Model Update

Update the `domains` and `layers` hooks and services based on the new `Layers` and `Domains` models and API definitions to accomodate the changes around predicates.

Remove `primary_predicate` from `Layer` related forms, tables, and pages.

Add `primary_predicate` and `primary_predicate_id` to `Domains` related forms, table, and pages.

## 3.1.2 Predicate CRUD components

The user should be able to create, update, and delete predicates from the set of predicates in their dataset.

- Create a form for creating and editing `Predicates` similar in concept to `LayerForm`
- Create a table for `Predicates` similar in concept to `LayersTable`
- Create a page for managing `Predicates` similar in concept to `src/routes/app/layers.tsx`
- Add a link to the `Predicates` page to the navigation alongside `Layers`, `Domains` and `Terms` in the nav menu
