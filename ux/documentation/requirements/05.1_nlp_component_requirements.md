# XX NLP Analysis UX

Enable the user to select context from the reference APIs to refine the suggested `title` and `definition` for a node.

## X.1 NLP Analysis Container

An NLP analysis container component should be created which enapsulates the NLP analysis, allowing the containing component to simply pass in a string for analysis.

### X.1.1 Token Selection for Analysis

Tokens where `is_stop` == false should each have their own `token_nlp_analysis` component.

### X.1.2 Token NLP Analysis Component

Create a `TokenNlpAnalysis` component which encompasses the following sub-components

- **TokenSenseList**: List the word senses in `wordnet.synsets` and allow the user to select the correct word sense, defaulting to the first match (they are listed by rank)

- **TokenConceptChart**: Chart the relationships uncovered by `concepcy.related_terms`

  - For each `related_term.relation` value, show the top n relations (default n=2)

  - The diagram should be similar to [05.99_concept_net_diagram.png](05.99_concept_net_diagram.png) which is an example of visualizing the nodes and links parsed by concepcy

### X.1.3 Entity Component

Create a `NlpEntityAnalysis` component which details any matched entities.
