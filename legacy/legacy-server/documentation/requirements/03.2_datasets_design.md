# Dataset Management Architecture Implementation

## 1. Overview

This document describes the implemented architecture for multiple dataset support in the Context Studio Local Server. The system enables users to manage multiple SQLite databases, each representing a distinct dataset, with complete lifecycle management including creation, import, switching, and removal capabilities.

## 2. Core Components

### 2.3 Platform-Specific Directory Management

The system supports configurable dataset storage with intelligent defaults:

#### Directory Resolution Priority:
1. **Constructor Parameter**: Explicit path passed to DatasetManager
2. **Configuration File**: `datasets_directory` field in `datasets.json`
3. **Environment Variable**: `DATASETS_DIRECTORY`
4. **Platform Default**: Platform-specific user document directories

#### Platform-Specific Defaults:
```python
def _get_default_datasets_directory(self) -> str:
    """Get platform-specific default datasets directory."""
    import platform
    home = os.path.expanduser("~")
    
    if platform.system() == "Windows":
        return os.path.join(home, "Documents", "ContextStudio", "datasets")
    else:  # macOS and Linux
        return os.path.join(home, "Documents", "ContextStudio", "datasets")
```

#### Directory Management Features:
- **Automatic Creation**: Dataset directory created if it doesn't exist
- **Path Validation**: Ensures directory is writable and accessible
- **Cross-Platform**: Works on Windows, macOS, and Linux
- **Runtime Reconfiguration**: Supports changing dataset directory during operation

#### Migration Implementation:
Each migration extends the base Migration class with atomic up/down operations:

```python
class Migration003(Migration):
    """Add vector search virtual tables."""
    
    version = 3
    description = "Add vector search tables"
    
    def up(self, connection: Connection) -> None:
        """Apply the migration with sqlite-vec extension loading."""
        try:
            import sqlite_vec
        except ImportError:
            raise RuntimeError("sqlite-vec extension not available. Install with: pip install sqlite-vec")
            
        raw_connection = connection.connection
        raw_connection.enable_load_extension(True)
        sqlite_vec.load(raw_connection)
        raw_connection.enable_load_extension(False)
        
        # Create vector tables for semantic search
        connection.execute(text("CREATE VIRTUAL TABLE IF NOT EXISTS terms_vec USING vec0(...)"))
        connection.execute(text("CREATE VIRTUAL TABLE IF NOT EXISTS domains_vec USING vec0(...)"))
        connection.execute(text("CREATE VIRTUAL TABLE IF NOT EXISTS layers_vec USING vec0(...)"))
    
    def down(self, connection: Connection) -> None:
        """Rollback the migration."""
        connection.execute(text("DROP TABLE IF EXISTS terms_vec"))
        connection.execute(text("DROP TABLE IF EXISTS domains_vec"))
        connection.execute(text("DROP TABLE IF EXISTS layers_vec"))
```

### 2.5 Enhanced Database Utils (`database/utils.py`)

Modified to support dynamic dataset switching:

```python
# Global state for current dataset
_current_engine = None
_current_session_local = None
_dataset_manager = None

def get_dataset_manager() -> DatasetManager:
    """Get the global dataset manager instance."""
    global _dataset_manager
    if _dataset_manager is None:
        _dataset_manager = DatasetManager()
    return _dataset_manager

def switch_active_database(dataset_id: str) -> bool:
    """Switch the active database connection."""
    global _current_engine, _current_session_local
    
    dataset_manager = get_dataset_manager()
    if dataset_manager.switch_dataset(dataset_id):
        _current_engine = dataset_manager.active_engine
        _current_session_local = dataset_manager.active_session_local
        return True
    return False

def get_current_engine():
    """Get the current active engine."""
    global _current_engine
    if _current_engine is None:
        # Initialize with default dataset
        dataset_manager = get_dataset_manager()
        _current_engine = dataset_manager.active_engine
    return _current_engine
```

### 5.2 Dependency Injection (`database/utils.py`)

```python
def get_db_for_current_dataset():
    """Get database session for currently active dataset."""
    session_local = get_current_session_local()
    if not session_local:
        raise HTTPException(status_code=500, detail="No active dataset")
    
    db = session_local()
    try:
        yield db
    finally:
        db.close()
```
