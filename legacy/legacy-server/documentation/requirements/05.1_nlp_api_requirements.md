# 5 NLP API

Provide an API which uses off-the-shelf NLP tools to analyze text to enrich, insipire and accelerate development of the data structure.

## 5.1 NLP Analysis API Endpoint

An API endpoint `/api/nlp_analysis` which takes a string and passes it through a spaCy pipeline, returning the pipeline result.

- API only supports the POST method with a `text` parameter in the body containing the text to analyze

  - `text` should have a configurable max length starting at 512 characters

  - If `text` is longer than the max length, an error should be returned and the string should not be analyzed

- The API will run the `text` through a spaCy pipeline

- The spaCy pipeline will include the following stages:

  - `concepCy` which identifies matching `ConceptNet` entities

    - [source](https://github.com/JulesBelveze/concepcy)

  - `dbpedia-spotlight` which identifies matching `DBpedia` entities

    - [source](https://github.com/MartinoMensio/spacy-dbpedia-spotlight)

  - `spacy-wordnet` which identifies matching `wordnet` entities

    - [source](https://github.com/argilla-io/spacy-wordnet)

  - `sense2vec` which provides insights to optimize the matched word sense

    - [source](https://github.com/explosion/sense2vec)

- The API should convert the full results of the spaCy pipeline to the client as a JSON object
