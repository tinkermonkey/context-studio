**Issue Title**: E2E Phase 0.2: Baseline test — taxonomy CRUD lifecycle

**Description**:
Implement `test_baseline_taxonomy_lifecycle` in `tests/e2e/test_phase0_baseline.py`. This test proves the complete entity hierarchy (layer → domain → terms) and relationship management work end-to-end via the HTTP API with a real database: create, list, filter, link, search, and delete.

## Requirements
- Create a full taxonomy hierarchy: one layer, one domain, four terms
- Create predicates and relationships (links) between terms
- Verify list and filter operations return correct subsets
- Verify semantic search returns relevant results with correct ranking
- Delete all created entities in reverse dependency order
- Verify clean state after deletion

## Design Guidance
**File**: `local-server/tests/e2e/test_phase0_baseline.py`

**Marker**: `@pytest.mark.e2e`

**Fixture**: Uses `e2e_client` from Phase 1 infrastructure (module-scoped). The `clean_tables` autouse fixture handles teardown regardless of failure.

**Test data**: Use `STABLE_TAXONOMY`, `STABLE_PREDICATES`, `STABLE_RELATIONSHIPS` from `tests/e2e/test_data.py` and `create_test_hierarchy` from `tests/e2e/helpers.py`.

**API surface used**:

| Operation | Endpoint | Expected Status |
|---|---|---|
| Create layer | `POST /api/structure_nodes/` | 201 |
| Create domain | `POST /api/structure_nodes/` | 201 |
| Create term | `POST /api/structure_nodes/` | 201 |
| List by type | `GET /api/structure_nodes/?node_type=layer` | 200 |
| Filter by parent | `GET /api/structure_nodes/?node_type=term&parent_node_id={id}` | 200 |
| Create predicate | `POST /api/predicates/` | 201 |
| Create link | `POST /api/structure_nodes/links` | 201 |
| List links | `GET /api/structure_nodes/links?source_node_id={id}` | 200 |
| Semantic search | `POST /api/structure_nodes/find` | 200 |
| Delete link | `DELETE /api/structure_nodes/links/{id}` | 204 |
| Delete predicate | `DELETE /api/predicates/{id}` | 200 |
| Delete term | `DELETE /api/structure_nodes/{id}` | 204 |
| Delete domain | `DELETE /api/structure_nodes/{id}` | 204 |
| Delete layer | `DELETE /api/structure_nodes/{id}` | 204 |

**List response shape** (from `api/models/structure_nodes.py`):
```json
{"data": [...], "total": N, "skip": 0, "limit": 50}
```

**Link create request shape**:
```json
{
  "source_node_id": "<uuid>",
  "target_node_id": "<uuid>",
  "predicate": "is_a",
  "predicate_id": "<predicate-uuid>"
}
```

**Search request shape**:
```json
{"query": "organized collection of data", "node_type": "term", "limit": 10}
```

**Search response**: array of scored results; `Database` must appear before `Firewall`-like unrelated terms.

**Deletion order** (required to avoid foreign key violations):
1. Links (all)
2. Predicates (all)
3. Terms (all)
4. Domain
5. Layer
