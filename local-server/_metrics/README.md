# Quality Metrics Artifacts

This directory contains JSONL metrics files generated by quality test suites and human evaluation:

**Automated Metrics:**
- `individual_extraction.jsonl` — Per-scenario metrics for the individual extraction pipeline
- `schema_extraction.jsonl` — Per-scenario metrics for the schema extraction pipeline
- `schema_node_grounding.jsonl` — Per-scenario metrics for the schema node grounding pipeline
- `schema_node_grounding_aggregate.jsonl` — Aggregate metrics across all grounding scenarios
- `connection_refinement.jsonl` — Per-scenario metrics for the schema node connection refinement pipeline
- `definition_refinement.jsonl` — Per-scenario metrics for the schema node definition refinement pipeline
- `_e2e_chain.jsonl` — Metrics for the end-to-end pipeline chain

**Human Evaluation Metrics:**
- `schema_node_definition_refinement_human_eval.jsonl` — Human ratings for the definition refinement pipeline
- `schema_node_connection_refinement_human_eval.jsonl` — Human ratings for the connection refinement pipeline

Each row in these JSONL files contains:
- `schema_version`: Version of the metrics schema
- `timestamp`: ISO 8601 timestamp when metrics were emitted
- `run_id`: Unique identifier for the test run
- `pipeline_type`: Pipeline being tested
- `scenario`: Specific test scenario
- `model`: Model identifier used
- `config_ref` / `config_version`: Configuration reference and version
- `mode`: Execution mode ("cassette" or "live")
- `source`: Source of metrics ("automated" or "human_eval")
- `metrics`: Dict of metric_name → metric_value pairs

These artifacts are produced by CI and can be queried for trend analysis, A/B comparison, and floor validation.
