# 5.2 NLP API Design

This document outlines the design for the NLP Analysis API endpoint that meets the requirements specified in 05.1_nlp_api_requirements.md.

## API Endpoint Design

### Endpoint

- **URL**: `/api/nlp_analysis`
- **Method**: `POST`
- **Content-Type**: `application/json`

### Request Schema

```json
{
  "text": "string (required, max 512 characters)"
}
```

## Implementation Design

### Configuration

- **Text Length Limit**: 512 characters (configurable via environment variable `NLP_MAX_TEXT_LENGTH`)
- **spaCy Model**: `en_core_web_sm`

### spaCy Pipeline Components

The pipeline will include the following components in order:

1. Standard spaCy components (tokenizer, tagger, parser, ner)
2. `concepcy` - for ConceptNet entity identification
3. `dbpedia_spotlight` - for DBpedia entity identification
4. `spacy_wordnet` - for WordNet entity identification
5. `sense2vec` - for word sense optimization and similarity

### File Structure

```
api/
├── nlp_analysis.py              # NLP analysis endpoint
nlp/
├── __init__.py
├── pipeline.py                  # spaCy pipeline setup and management
├── processors.py                # Custom processing functions
└── models.py                    # Pydantic models for request/response
```

### Core Components

#### 1. Pydantic Models (`nlp/models.py`)

```python
"""
Pydantic models for NLP analysis requests and responses.
"""

from typing import List, Optional, Any, Dict
from pydantic import BaseModel, Field

class NLPAnalysisRequest(BaseModel):
    """
    Request model for NLP analysis API.
    """
    text: str = Field(..., description="Text to analyze.")

class ConcepcyData(BaseModel):
    """
    ConceptNet/Concepcy data for a token.
    """
    related_terms: Optional[List[str]] = Field(default_factory=list, description="Related terms from ConceptNet.")
    score: Optional[float] = Field(None, description="ConceptNet similarity score.")

class Sense2VecData(BaseModel):
    """
    Sense2Vec data for a token.
    """
    in_s2v: bool = Field(default=False, description="Whether token is in sense2vec model")
    key: Optional[str] = Field(None, description="Sense2vec key (e.g., 'duck NOUN')")
    freq: Optional[int] = Field(None, description="Frequency in sense2vec corpus")
    other_senses: List[str] = Field(default_factory=list, description="Other senses for this word")
    most_similar: List[Dict[str, Any]] = Field(default_factory=list, description="Most similar words with scores")

class WordNetData(BaseModel):
    """
    WordNet data for a token.
    """
    synsets: Optional[List[dict]] = Field(
        default_factory=list,
        description="WordNet synsets with attributes, including domain context. Each synset dict includes: name, definition, lemmas, pos, offset, domain."
    )
    lemmas: Optional[List[dict]] = Field(default_factory=list, description="WordNet lemmas with attributes.")
    definitions: Optional[List[str]] = Field(default_factory=list, description="WordNet definitions.")

class DBpediaData(BaseModel):
    """
    DBpedia data for an entity.
    """
    uri: Optional[str] = Field(None, description="DBpedia URI.")
    label: Optional[str] = Field(None, description="DBpedia label.")
    similarity: Optional[float] = Field(None, description="DBpedia similarity score.")
    raw_result: Optional[Any] = Field(None, description="Raw DBpedia result.")

class TokenData(BaseModel):
    """
    Data for a single token in the analyzed text.
    """
    text: str = Field(None, description="Token text.")
    lemma: Optional[str] = Field(None, description="Token lemma.")
    pos: Optional[str] = Field(None, description="Part of speech tag.")
    tag: Optional[str] = Field(None, description="Detailed POS tag.")
    start: int = Field(None, description="Start character position.")
    end: int = Field(None, description="End character position.")
    concepcy: Optional[ConcepcyData] = Field(default_factory=ConcepcyData, description="Concepcy data.")
    wordnet: Optional[WordNetData] = Field(default_factory=WordNetData, description="WordNet data.")
    sense2vec: Optional[Sense2VecData] = Field(default_factory=Sense2VecData, description="Sense2vec data.")

class EntityData(BaseModel):
    """
    Data for a named entity in the analyzed text.
    """
    text: str = Field(..., description="Entity text.")
    label: Optional[str] = Field(None, description="Entity label.")
    kb_id: Optional[str] = Field(None, description="Knowledge base ID.")
    dbpedia: Optional[DBpediaData] = Field(None, description="DBpedia data.")

class NLPAnalysisResponse(BaseModel):
    """
    Response model for NLP analysis API.
    """
    tokens: List[TokenData] = Field(default_factory=list, description="List of token data.")
    entities: List[EntityData] = Field(default_factory=list, description="List of entity data.")
    text: str = Field(..., description="Original analyzed text.")

class SuccessResponse(BaseModel):
    """
    Success response wrapper for NLP API.
    """
    success: bool = Field(default=True, description="Indicates success.")
    data: NLPAnalysisResponse

class ErrorResponse(BaseModel):
    """
    Error response wrapper for NLP API.
    """
    success: bool = Field(default=False, description="Indicates failure.")
    error: str = Field(..., description="Error message.")
```

```python
import spacy
from spacy.lang.en import English

  "local_path": "./downloads/s2v_reddit_2015_md"
}
s2v_config["abs_path"] = os.path.abspath(s2v_config["local_path"])

class NLPPipeline:
    def __init__(self):
        self.nlp = None
        self._initialize_pipeline()

    def _initialize_pipeline(self):
        """Initialize the spaCy pipeline with all required components"""
        try:
            # Load the English model
            self.nlp = spacy.load('en_core_web_sm')

            # Add custom components
            self.nlp.add_pipe("concepcy")
            self.nlp.add_pipe('dbpedia_spotlight')
            self.nlp.add_pipe("spacy_wordnet", after='tagger')
            self.s2v = self.nlp.add_pipe("sense2vec")

            # Load the SV2 dataset
            print(f"Loading sense2vec model from {s2v_config["abs_path"]}...")
            self.s2v.from_disk(s2v_config["abs_path"])

        except OSError as e:
            raise RuntimeError(f"Failed to load spaCy model: {e}")
        except Exception as e:
            raise RuntimeError(f"Failed to initialize NLP pipeline: {e}")

    def process(self, text: str):
        """Process text through the spaCy pipeline"""
        if not self.nlp:
            raise RuntimeError("Pipeline not initialized")

        return self.nlp(text)

# Global pipeline instance
_pipeline = None

def get_pipeline() -> NLPPipeline:
    """Get or create the global pipeline instance"""
    global _pipeline
    if _pipeline is None:
        _pipeline = NLPPipeline()
    return _pipeline
```

#### 3. Data Processors (`nlp/processors.py`)

```python
from typing import List
from .models import TokenData, EntityData, ConcepcyData, WordNetData, DBpediaData, Sense2VecData, NLPAnalysisResponse

def extract_token_data(doc) -> List[TokenData]:
    """Extract token-level data from spaCy doc"""
    tokens = []

    for token in doc:
        # Extract ConceptNet data
        concepcy_data = ConcepcyData()
        if hasattr(token._, 'concepcy') and token._.concepcy:
            if hasattr(token._.concepcy, 'related_terms'):
                concepcy_data.related_terms = token._.concepcy.related_terms
            if hasattr(token._.concepcy, 'score'):
                concepcy_data.score = token._.concepcy.score

        # Extract WordNet data
        wordnet_data = WordNetData()
        if hasattr(token._, 'wordnet') and token._.wordnet:
            try:
                # Extract synsets as dictionaries with full information
                synsets = []
                for synset in token._.wordnet.synsets():
                    synset_dict = {
                        "name": synset.name(),
                        "definition": synset.definition(),
                        "lemmas": [lemma.name() for lemma in synset.lemmas()],
                        "pos": synset.pos(),
                        "offset": synset.offset(),
                        "domain": getattr(synset, 'lexname', lambda: 'unknown')()
                    }
                    synsets.append(synset_dict)
                wordnet_data.synsets = synsets

                # Extract lemmas as dictionaries with count information
                lemmas = []
                for lemma in token._.wordnet.lemmas():
                    lemma_dict = {
                        "name": lemma.name(),
                        "synset": lemma.synset().name(),
                        "count": lemma.count()
                    }
                    lemmas.append(lemma_dict)
                wordnet_data.lemmas = lemmas

                # Extract definitions
                wordnet_data.definitions = [synset.definition() for synset in token._.wordnet.synsets()]
            except:
                pass  # Handle cases where wordnet data is not available

        # Extract Sense2Vec data
        sense2vec_data = Sense2VecData()
        if hasattr(token._, 'in_s2v'):
            try:
                sense2vec_data.in_s2v = token._.in_s2v
                if hasattr(token._, 's2v_key'):
                    sense2vec_data.key = token._.s2v_key
                if hasattr(token._, 's2v_freq'):
                    sense2vec_data.freq = token._.s2v_freq
                if hasattr(token._, 's2v_other_senses'):
                    sense2vec_data.other_senses = token._.s2v_other_senses
                if hasattr(token._, 's2v_most_similar'):
                    most_similar = token._.s2v_most_similar(5)
                    if most_similar:
                        sense2vec_data.most_similar = [
                            {"word": similar[0][0], "sense": similar[0][1], "score": similar[1]}
                            for similar in most_similar
                        ]
            except:
                pass  # Handle cases where sense2vec data is not available

        token_data = TokenData(
            text=token.text,
            lemma=token.lemma_,
            pos=token.pos_,
            tag=token.tag_,
            start=token.idx,
            end=token.idx + len(token.text),
            concepcy=concepcy_data,
            wordnet=wordnet_data,
            sense2vec=sense2vec_data
        )
        tokens.append(token_data)

    return tokens

def extract_entity_data(doc) -> List[EntityData]:
    """Extract entity-level data from spaCy doc"""
    entities = []

    for ent in doc.ents:
        # Extract DBpedia data
        dbpedia_data = DBpediaData()
        if hasattr(ent, 'kb_id_') and ent.kb_id_:
            dbpedia_data.uri = ent.kb_id_

        if hasattr(ent._, 'dbpedia_raw_result') and ent._.dbpedia_raw_result:
            dbpedia_data.raw_result = ent._.dbpedia_raw_result
            if '@similarityScore' in ent._.dbpedia_raw_result:
                dbpedia_data.similarity = float(ent._.dbpedia_raw_result['@similarityScore'])
            if '@URI' in ent._.dbpedia_raw_result:
                dbpedia_data.uri = ent._.dbpedia_raw_result['@URI']

        entity_data = EntityData(
            text=ent.text,
            label=ent.label_,
            kb_id=getattr(ent, 'kb_id_', None),
            dbpedia=dbpedia_data
        )
        entities.append(entity_data)

    return entities

def process_nlp_result(text: str, doc) -> NLPAnalysisResponse:
    """Process spaCy doc into structured response"""
    tokens = extract_token_data(doc)
    entities = extract_entity_data(doc)

    return NLPAnalysisResponse(
        text=text,
        tokens=tokens,
        entities=entities
    )
```

#### 4. API Endpoint (`api/nlp_analysis.py`)

```python
from fastapi import APIRouter, HTTPException, status
from fastapi.responses import JSONResponse
from nlp.models import NLPAnalysisRequest, SuccessResponse, ErrorResponse
from nlp.pipeline import get_pipeline
from nlp.processors import process_nlp_result
from utils.logger import get_logger

logger = get_logger(__name__)

router = APIRouter()

settings = {
  #'NLP_MAX_TEXT_LENGTH': 512
}

@router.post("/nlp_analysis", response_model=SuccessResponse)
async def analyze_text(request: NLPAnalysisRequest):
    """
    Analyze text using spaCy pipeline with ConceptNet, DBpedia, WordNet, and Sense2Vec components.

    - **text**: Text to analyze (max 512 characters)
    """
    try:
        # Validate text length
        max_length = getattr(settings, 'NLP_MAX_TEXT_LENGTH', 512)
        if len(request.text) > max_length:
            error_response = ErrorResponse(
                error=f"Text exceeds maximum length of {max_length} characters"
            )
            return JSONResponse(
                status_code=status.HTTP_400_BAD_REQUEST,
                content=error_response.dict()
            )

        # Get pipeline and process text
        pipeline = get_pipeline()
        doc = pipeline.process(request.text)

        # Extract structured data
        analysis_result = process_nlp_result(request.text, doc)

        # Return success response
        return SuccessResponse(data=analysis_result)

    except RuntimeError as e:
        logger.error(f"Pipeline error: {e}")
        error_response = ErrorResponse(
            error="Failed to initialize or run NLP pipeline"
        )
        return JSONResponse(
            status_code=status.HTTP_500_INTERNAL_SERVER_ERROR,
            content=error_response.dict()
        )

    except Exception as e:
        logger.error(f"Unexpected error in NLP analysis: {e}")
        error_response = ErrorResponse(
            error="An unexpected error occurred during analysis"
        )
        return JSONResponse(
            status_code=status.HTTP_500_INTERNAL_SERVER_ERROR,
            content=error_response.dict()
        )
```

## Error Handling

The API handles the following error cases:

- **TEXT_TOO_LONG**: Text exceeds configured maximum length
- **PIPELINE_ERROR**: Failed to initialize or run the NLP pipeline  
- **INTERNAL_ERROR**: Unexpected errors during processing

All errors return a simple error response format with a descriptive message.

## Performance Considerations

- Pipeline initialization is expensive, so we use a singleton pattern
- Consider adding caching for frequently analyzed text
- Monitor memory usage with large text inputs
- Consider async processing for very long texts

## Testing Strategy

- Unit tests for each processor function
- Integration tests for the full pipeline
