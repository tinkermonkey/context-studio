# 9.1 NLP Enrichment API

Provide an API which will retrieve context from reference APIs and return it in structured format.

## 9.1.1 Layered Architecture

Build the core functionality of retrieving the context from the reference APIs using a re-useable python service which can be utilized by the API and also in other areas of the application.

## 9.1.2 Utilize Caching Proxy

Utilize the caching proxy setup for each reference API if it is enabled for that source.

## 9.1.3 Reference API Support

Provide the following methods for communicating with the upstream reference sources:

- DBPedia.org

  - Retrieve structured data from a DBpedia resource URL by converting it to a `data` url and fetching the data

  - Retrieve structured data from DBpedia by invoking the dbpedia `/search` API

  - Retrieve structured data from DBpedia by invoking a spaql query via the `/sparql` endpoint

- ConceptNet

  - Retrieve structured data from ConceptNet `query` based on term or term and relation:

  ```
  GET /query?start=/c/en/{term}&rel=/r/{relation}
  GET /query?end=/c/en/{term}
  GET /query?node=/c/en/{term}
  ```

  - Retrieve structured data from ConceptNet based on a specific (known) concept and (optionally) a known relation to another known concept:

  ```
  GET /c/en/{concept}
  GET /c/en/{concept1}/r/{relation}/{concept2}
  ```

  - Retrieve structured data about related concepts from ConceptNet `related` API:

  ```
  GET /related/c/en/{concept}
  GET /related/c/en/{concept}?filter=/c/en
  ```

- WikiData

  - Retrieve structured data from Wikidata via the `https://query.wikidata.org/sparql` endpoint

  - Retrieve structured data from Wikidata by converting a wikidata webpage url into a structured data request

- Schema.org

  - Retrieve structured data from the local `schema.org` database for entities and properties

    - For entities, return the entity and all of the properties for that entity as well as the inherited properties from parent entity types

    - For properties, return the property definition and a list of entities which use that property
