# Moving Data

This document outlines the requirements for being able to move segments of a graph around as branches rather than just individual nodes.

## 1. Move with lineage

Users should be able to move nodes in the graph and move all sub nodes at the same time:

- Move a domain or a set of domains from one layer to another, with all terms in that domain also changing to the new layer
- Move a term or a set of terms from one domain to another, with all child-terms also changing to the new domain

## 2. Orphaning child terms for safe deletion

Users should be able to remove terms without cascading deletes by first moving child terms to avoid data loss:

- Move child terms to another parent term within the same domain before deleting the original parent
- Move child terms to have no parent (orphan them) before deleting the original parent
- This allows for safe deletion of terms without losing their child terms
